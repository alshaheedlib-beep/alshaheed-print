# مطبعة الشهيد — المتجر

نسخة تجريبية لمتجر مطبعة الشهيد (الخليل – دائرة السير)، على نمط doprint.ps وباللون الكحلي.

- `site/` — الموقع نفسه (صفحة واحدة + الأيقونات + صور الأقسام).
- `install.sh` — تركيب على السيرفر مرة واحدة.

## التركيب على السيرفر (مرة واحدة)

```
curl -fsSL https://raw.githubusercontent.com/alshaheedlib-beep/alshaheed-print/main/install.sh | bash
```

بيشغّل الموقع على المنفذ 8081، وبيربطه بـ `alshaheed.ps` عن طريق Caddy إذا موجود، وبيفعّل سحب تلقائي من GitHub كل دقيقة.

## التحديث

أي تعديل يُرفع على فرع `main` يظهر على الموقع خلال دقيقة تقريباً.
