# مطبعة الشهيد — المتجر

متجر مطبعة الشهيد (الخليل – دائرة السير) بالعربي والإنجليزي، مع لوحة تحكم. بدون أي حزم خارجية: Node.js 22 فقط (SQLite مدمجة).

## الأقسام
| القسم | طريقة الطلب |
| --- | --- |
| اللافتات والواجهات | طلب عرض سعر (مقاسات + صورة) — والرول أب والبانرات شراء مباشر |
| المطبعة | سلة: مقاسات، حد أدنى، خصم كميات، رفع الشعار عند تثبيت الطلب |
| التسويق والإعلان | طلب عرض سعر للباقات والحملات |
| الجملة والمواد الخام | سلة بأسعار جملة وخصم كميات |

## لوحة التحكم `/admin`
- **الطلبات**: الشعار المرفوع، ملاحظات الطباعة، الحالة (جديد ← بالتصميم ← تم اعتماد التصميم ← بالطباعة ← خرج للتوصيل ← تم التسليم)، واتساب العميل.
- **طلبات عروض الأسعار**: المقاسات، الصورة/الملف، الحالة وملاحظات داخلية.
- **المنتجات**: خيارات بأسعار، الوحدة، الحد الأدنى، الزيادة، خصم الكميات (`1000:5, 3000:10`)، مدة التنفيذ، شراء مباشر أو عرض سعر، صورة.
- **الأقسام والفئات**: رفع صورة/أيقونة PNG لكل قسم وفئة.
- **مناطق التوصيل** و**الإعدادات** (واتساب، العنوان، طرق الدفع…).

## السيرفر
تركيب مرة واحدة:
```
curl -fsSL https://raw.githubusercontent.com/alshaheedlib-beep/alshaheed-print/main/install.sh | bash
```
- المتجر على المنفذ 8081 وعلى `alshaheed.ps` عبر Caddy.
- البيانات والصور في `/opt/alshaheed-data` (تبقى مع كل تحديث). كلمة سر اللوحة في `/opt/alshaheed-data/admin-password.txt`.
- كل دقيقة يفحص GitHub، وعند وجود تعديل يبني المتجر من جديد (`deploy/update.sh`، السجل في `/var/log/alshaheed-print-deploy.log`).

## محلياً
```
npm start   # http://localhost:3000  —  /admin
```
